# React 19, Vite 8 and strict TypeScript, with the server as Vite middleware

Date: 2026-11-04 · Status: accepted

## Context

One user, one machine. The dashboard will read git, a few files and `gh`, poll every 3 s, and serve three routes to one page. Its contract parser must also run inside other repos' Node gates with no install step. Shane's default stack (new-dev-project) is React + Vite + TS strict, Vitest, oxlint, a Hono API on Vercel, Supabase and Playwright.

## Options

- **The default front end, server as a Vite middleware plugin** — one process and one port per checkout, one config every tool reads; the tracker's `dev/progress-plugin.ts` is the precedent / the server exists only while the dev server runs; `vite build` output has none.
- **The full default (Hono, Vercel, Supabase, Playwright)** — familiar / Vercel cannot read local disk; git and `~/.devdash` already hold everything worth storing; Hono is a router for three routes.
- **A standalone Node server beside a static UI** — independent of Vite / two processes and two ports per lane, for no gain.
- **Python** — Shane's strength / the parser must run in Apex's and the tracker's Node gates; two toolchains for one small UI.

## Decision

React 19.3, Vite 8.3, TypeScript strict (`tsc -b` in the gate), Vitest 5.1 on jsdom with Testing Library, oxlint, prettier, Node 26 (`.nvmrc`). Phase 1 adds the server as `src/server/plugin.ts`, a Vite middleware. `contract/` will be plain `.mjs` with `.d.mts` types and Node builtins only (the pattern of Apex's `merge-policy.mjs`), so it vendors into any repo with no dependencies and no build.

Not taken, deliberately:

- Hono, Supabase, Vercel: nothing to host, nothing to store.
- A router library: one hash route through `useSyncExternalStore`.
- SSE and file watchers: polling with ETag instead. Per-path watchers over about 100 worktrees would exhaust macOS's soft limit of 256 file descriptors.
- Playwright, for now: every panel will be a pure function of one snapshot, which jsdom tests reach.

TypeScript 7.0 (`~7.0.2`) is the generator's default. It is kept, not downgraded.

## Revisit when

- A second machine or a phone view is wanted: a private store, never a public deploy.
- A snapshot takes over 150 ms, or lag is visible: SSE or `fs.watch`.
- A UI regression ships that only a real browser would have caught: Playwright joins, outside the lane gate if slow.
- A tool in the chain breaks on TypeScript 7: pin 6.x and record why.
